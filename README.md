# engine-lex-pattern

`hnl-engine-lex-pattern` — A **data-driven** lexer engine that reads [`LexerRuleDef`] fragments from a [`Language`] and tokenizes source text (ADR-0044 §1, §3).

Sibling-repo deps are git dependencies (`branch = "main"`); the `[patch]`
tables resolve them from sibling checkouts for local development.
